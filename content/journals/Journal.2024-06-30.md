### Learning: SwiftUI Views
- Data binding using @Binding modifier 
- Generating observable modals using @Observable
- Passing the observable modals using @Environment to the below view.
- @State for state and changing values based on them.
- The basics of app development is done with a lot of topics discussed. 

The app is usable with some visible state, data manipulation, and view bindings. However, there is a lot of work to do just to make a basic app including database, network calls, api request and many more. Although the process seems fairly simple as a lot of the basic foundation of making an app is already laid out by Apple, making complex apps is a different feat altogether.

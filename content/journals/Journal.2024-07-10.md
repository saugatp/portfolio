### Learning: Filter mode and visual changes 
Something I am really bad at is implementing filters in my app. A lot of filter options are so complicated if the relative implementation are really bad. And such has been the case for me multiple times. As well as saving the filter options in device so that the last used filter is displayed as default makes it even harder. However, a greater feat is showing the filter screen without any complications. Today, I achieved the following in iOS journey:
- Implemented filters for radius selection and london bus station only option
- Implemented local search in the list itself(relatively easy)
- Visual tweaks like showing the bus icon in red if it's london bus and blue if otherwise
